## 常见问题

**绿云 KVM VPS 能装 Windows 吗？**
KVM 产品线只提供 Linux 系统。需要 Windows 的话，绿云有单独的 Budget Windows VPS 线（$8/月起），配置和计费方式不同。

**亚太机房流量够用吗？**

**10Gbps 端口是独享的吗？**
标称值。商家页面和第三方评测都明确说明：实际速度受宿主资源、网络拥塞、路由和流量策略影响，亚太部分节点实标 1Gbps。

**绿云口碑怎么样？**
官网自述曾获 LowEndTalk 的「#1 Most Stable Provider」等称号，但第三方评测机构 itechguides 在 2026 年 10 月给出的评分是 7.6/10，在其美国 VPS 商家榜单里只排第 22/23。两边的口径存在明显分歧，比较稳妥的看法是：它是个合格的低价商家，但别按高端商家的预期去要求工单响应和线路质量。
